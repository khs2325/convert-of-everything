# Format icon sources

These assets are stored locally so the format globe does not contact third-party
servers while a visitor uses the converter.

- `aseprite.png`: <https://github.com/aseprite/aseprite/blob/main/data/icons/ase256.png>
- `piskel.png`: <https://github.com/piskelapp/piskel-website/blob/master/static/resources/favicon-v2.png>
- `pixelorama.png`: <https://github.com/Orama-Interactive/Pixelorama/blob/master/assets/graphics/icons/icon.png>
- `pixilart.ico`: <https://www.pixilart.com/favicon.ico>
- `krita.ico`: <https://krita.org/favicon.ico>
- `json.gif`: <https://www.json.org/img/json160.gif>
- `png.png`: <https://www.libpng.org/pub/png/img_png/pnglogo-blk-tiny.png>

Formats without clearly published official artwork use the converter's neutral
file badge. The Adobe Photoshop product icon is intentionally not redistributed.
